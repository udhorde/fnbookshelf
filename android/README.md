# 飞牛书屋 Android 客户端

两个独立的安装包，功能都是打开你 NAS 上的飞牛书屋网页版，区别只在交互方式。

| 文件 | 用途 | 包名 |
|---|---|---|
| `out/fnbookshelf-android-phone-<版本>.apk` | 手机、平板 | `com.fnbookshelf.reader` |
| `out/fnbookshelf-android-tv-<版本>.apk` | 电视、电视盒子 | `com.fnbookshelf.tv` |

- 最低系统：Android 5.0（API 21），目标 API 34
- 已用 `keystore/fnb.jks` 签名（v1 + v2）
- 不依赖 Gradle，`bash build.sh` 直接用 SDK 的 aapt2 / d8 / apksigner 出包

## 安装

**手机 / 平板**：把 APK 拷到手机，用文件管理器点开安装（需要在系统设置里允许「安装未知来源应用」）。

**电视**：用「当贝市场 / 沙发管家」的远程推送，或者 U 盘 + 电视自带的文件管理安装。装好后会出现在电视桌面的应用列表里（带 banner）。

两个包可以同时装在一台设备上，互不冲突。

## 首次使用

1. 打开应用 → 出现「连接到你的 NAS 书库」
2. 填 NAS 地址，**只填主机和端口**即可，例如 `192.168.1.10:8096` 或 `nas.example.com:8096`
   - 不写协议会自动用 `https`
   - 写 `http://` 也行，但飞牛书屋默认是 https
3. 点「测试连接」，成功会显示站名和耗时
4. 点「进入书屋」→ 保存并打开

连不上时可以点「仍然保存并尝试打开」——有些网络（比如 Tailscale 中转）探测会超时但实际能打开。

## 手机 / 平板端

- 跟随系统方向，横竖屏、分屏都能用
- 状态栏与网页同色，软键盘弹出时页面收缩而不是被遮住
- 返回键：网页能后退就后退，退到底弹设置面板
- 下载：网页里点「下载」会把文件存到系统「下载 / 飞牛书屋」（Android 10 以下存到应用目录）
- 长按选词、复制粘贴、双指缩放在阅读器里都可用

## TV 端

- 强制横屏、全屏沉浸，无触摸屏声明（不会被当成手机应用）
- 遥控器操作：**方向键移动高亮框，确定键点击，返回键**：
  - 网页能后退就后退
  - 退到首页弹出小面板：服务器设置 / 刷新页面 / 退出
- 输入框（搜索、服务器地址）按确定键会弹出**原生输入框**，用电视自带的输入法打字
- 网页文字放大到 140%，电视机上更好认

## 出问题时

| 现象 | 处理 |
|---|---|
| 一直停在「连接到你的 NAS 书库」 | 地址填错或 NAS 没开机，用电脑浏览器先验证同一地址能打开 |
| 显示「连不上服务器」 | 页面上有具体原因和排查清单，点「重试」或「修改地址」 |
| 电视上高亮框不出现 | 按一下方向键；仍不行说明网页 DOM 结构变了，需要更新 `assets-tv/tv-nav.js` 里的选择器 |
| 下载没反应 | 只支持网页里的 `<a download>` 链接；超大文件（>512MB）会被拒绝 |

## 改代码后重新打包

```bash
bash build.sh          # 产出 out/*.apk，约 20 秒
```

- 版本号在 `build.sh` 顶部（`VERSION` / `VCODE`）
- 改界面改 `assets-common/setup.html`（首次配置）、`error.html`（出错页）
- 改下载逻辑改 `assets-common/fnb-common.js`
- 改 TV 遥控器逻辑改 `assets-tv/tv-nav.js`
- 改原生行为改 `src/core/com/fnbookshelf/core/*.java`
- 图标：`node tools/gen-icons.js` 重新生成（需要本机 Chrome）

**签名密钥不要丢**：`keystore/fnb.jks` 以及它的口令**都不入库**，请自行备份。构建时口令按这个顺序取：

1. 环境变量 `FNB_KS_PASS`
2. `keystore/.kspass`（一行口令，同样被 gitignore）
3. 都没有且密钥文件也不存在时，`build.sh` 会随机生成一个并写进 `keystore/.kspass`

```bash
FNB_KS_PASS='你的口令' bash build.sh
```

换了密钥，新包无法覆盖安装旧包，必须先卸载。
